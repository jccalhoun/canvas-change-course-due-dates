Quick Start

  1. Choose Configure API Settings and enter your Canvas Instance and your Access Token.
  2. Choose Specify Course and put in the Canvas Course ID for the course to analyze. This will automatically run Load Due Dates so you can skip the next step.
  3. Choose Load Due Dates to download all of the due dates from Canvas. Note that this will erase any existing data.
  4. Modify the dates. If you put dates without times into the Due or Available Until fields, it will set them to the end of the day.
  5. Choose Save Due Dates to save your changes to Canvas.

Mass Editing Tools

The Shift All Dates... menu item allows you to push all Due, Available From, Available Until, and Show/Hide dates forward or backward by a specific number of days.

The Remap Date Range... menu item allows you to pick a date your schedule is currently anchored to and the date it should move to. The entire sheet will shift perfectly to match the new timeline.

The Apply Availability Rules... menu item automatically populates "Available From" and "Available Until" dates based on each assignment's Due date (e.g., automatically unlock everything 7 days before it is due).

Display Settings

If your times aren't correct, it may be a timezone issue. The spreadsheet's timezone settings are found under the File > Settings menu item and should be set to match your local timezone before you download the due dates.

The Hide Times menu item will hide the times, leaving just the dates, for any dates at the start or end of the day. If the time is in the middle of the day, then it will continue to show the time. This is cosmetic and only affects how the date is displayed, not the date itself.

The Show Times menu item will show the time for all dates. This will allow you to confirm the times. It will also allow you to do a find and replace on the times.

Points Column

Point values are shown for reference only.

Due to Canvas Classic Quiz limitations, changes made to the Points column are not saved back to Canvas. All other supported fields (Due Date, Available From, Available Until, Published, Show Answers, Hide Answers) continue to function normally.
