Quick Start

  1. Choose Configure API Settings and enter your Canvas Instance and your Access Token.
  2. Choose Specify Course and put in the Canvas Course ID for the course to analyze. This will automatically run Load Due Dates so you can skip the next stop.
  3. Choose Load Due Dates to download all of the due dates from Canvas. Note that this will erase any existing data.
  4. Modify the dates. If you put dates without times into the Due or Available Until fields, it will set them to the end of the day.
  5. Choose Save Due Dates to save your changes to Canvas.

If your times aren't correct, it may be a timezone issue. The spreadsheet's timezone settings are found under the File > Spreadsheet Settings menu item and should be set before you download the due dates.

The Hide Dates menu item will hide the times, leaving just the dates, for any dates at the start or end of the day. If the time is in the middle of the day, then it will continue to show the time. This is cosmetic and only affects how the date is displayed, not the date itself.

The Show Dates menu item will show the time for all dates. This will allow you to confirm the times. It will also allow you to do a find and replace on the times.

The Due at End of Minute menu item will adjust times for the due date or available until date so to be the end of the minute rather than the start of the minute. This only changes them in the spreadsheet; you will still need to save the changes to Canvas before they take affect.
